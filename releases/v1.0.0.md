# v1.0.0

29 October 2026. These notes describe the product. They do not create a git tag and they do not publish a GitHub release.

## What shipped

The template can be copied into an app, filled through design.md §16, and checked with lint, render and axe. Two examples show the filled shape.

| | Godavari Ferry | Sodium Yard |
|---|---|---|
| Path | `examples/godavari-ferry` | `examples/sodium-yard` |
| Feel | A paper ticket you can read in full sun | The yard at night |
| Default theme | light | dark |
| Other theme | dark, via `prefers-color-scheme` | light, via `prefers-color-scheme` |
| Type | Fraunces, Atkinson Hyperlegible | Bricolage Grotesque, Public Sans |
| system_version | 0.9.0 | 0.9.0 |

Both ship real woff2 files and an OFL. Both leave marketing and motion switched off. Chart series stay on the Okabe–Ito set. Sodium's dark series 6 is one step lighter so it stays at 3:1 on that yard's raised surface.

Quick starts for both brands are in [seeds.yaml](../seeds.yaml). The short agent card is [RULES.md](../RULES.md). The comparison with Stitch, v0, Aura, designmd.ai, shadcn/ui and Figma variables is [design-build/references/competitors.md](../design-build/references/competitors.md).

## Versions, kept apart

- **Product:** 1.0.0, this note and [CHANGELOG.md](../CHANGELOG.md).
- **Document schema:** `template_version: 2.0.0` in design.md front matter.
- **Starter system version:** the unfilled placeholder. Do not write 1.0.0 there. That number is for a brand that has finished Phase 5.
- **Example system versions:** 0.9.0 until a Phase 5 review accepts them.

## Using it in an app

See the README section "Use it in a Vite or Next app". Import the brand's `fonts.css`, then `design-build/preview/tokens.css`, then `components/base.css`. Render the running app with `node design-build/render.mjs --url` (Vite `http://localhost:5173/`, Next `http://localhost:3000/`).
