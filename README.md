# Design System Template

A universal, AI-readable design system template for any brand and any design work: apps and websites, marketing and content, motion and video, and print.

- **Start here:** [`design.md`](design.md) is the index. It covers the conventions, which file owns what, the precedence rules, the agent rules, and the §16 build workflow.
- **Core (always used):** [`design/core.md`](design/core.md), §1–§14 (brand foundation through governance, with §13 tokens as the single source of truth).
- **Optional modules:** [`digital-product.md`](design/digital-product.md), [`marketing-content.md`](design/marketing-content.md), [`motion-video.md`](design/motion-video.md), [`print.md`](design/print.md).
- **Kick off a build:** drop this folder into any project and paste [`KICKSTART.md`](KICKSTART.md) into your coding harness.
- **Working files:** `design-build/` (state, research notes, studies, preview), `assets/` (logo, icons, imagery, motion, moodboard…), `tokens/tokens.json`.
