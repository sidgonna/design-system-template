# Fonts

SIL Open Font License 1.1. The OFL-*.txt files are the licenses.

- Fraunces (latin variable) is the heading. Source Serif 4 is the second family in that stack and is shipped, so a missing glyph does not use a system serif.
- Atkinson Hyperlegible is the body, for older passengers and jetty glare.
- JetBrains Mono is the mono role.
- Noto Sans Telugu and Noto Sans Devanagari cover te and hi.
