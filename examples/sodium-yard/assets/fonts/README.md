# Fonts

SIL Open Font License 1.1. The OFL-*.txt files are the licenses.

- Bricolage Grotesque (latin variable, weight axis 200–800) is the heading. Public Sans is the second family in that stack and is shipped, so a missing glyph does not use a system sans.
- Public Sans is the body, a civic grotesque for the night desk.
- JetBrains Mono is the mono role, for lamp IDs.
- Noto Sans Telugu and Noto Sans Devanagari cover te and hi on the specimen.
