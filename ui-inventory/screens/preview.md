## Layout
- **Order, top to bottom:**
  1. A header with the theme toggle.
  2. The specimen bento: brand, type, buttons, inputs, cards, badges, motion and the coverage ring.
  3. A catalog grouped as Actions, Inputs, Feedback, Navigation, Data display and Layout. Each group is a brand specimen. Patterns (form, empty state, data table, settings) sit under the group they belong to.
  4. Guidelines and Coverage are separate board views. Guidelines groups the component tiles the same way.
- **Reflow:** the bento and the catalog stack on a narrow viewport. Tables scroll inside their region. Component rows wrap.

## Notes
- **Purpose:** this is a review screen, not a product screen. It shows every shipped component, grouped, so the reviewer and `design-build/render.mjs` (axe, the reflow check, screenshots) and `design-build/motion.mjs` can check them.
- **Markup:** it uses the shipped `components/components.css` through the HTML API (`data-component`), the same CSS the React wrappers render. `components/boot.js` wires tabs, switches, dialogs, tooltips and toast dismiss.
